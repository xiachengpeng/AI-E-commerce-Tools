## 事实与边界

- 现有功能依据：`frontend/index.html` 尺寸重绘视图、`frontend/js/square_redraw.js`、`frontend/css/square_redraw.css`。
- 本批新上传替换当前列表，并非追加；设计用“更换本批图片”明确表达。
- 10 种支持比例全部保留；宽高输入折算为支持的比例，不承诺固定输出像素。
- 已匹配比例的原图保留并进入 ZIP；已开始批次的比例锁定。
- 单图预览/移除、失败重试、图床、图片翻译、详情页流转、批次历史、ZIP 都有对应入口。
- 图床、流转、历史、ZIP 按钮只展示说明；不会操作现有数据或调用业务服务。
- 演示开始按钮只在浏览器内更新示例状态，不触发 AI。结果图片复用原图，不代表真实重绘效果。
- 本地选择图片仅在浏览器创建预览，不上传文件。刷新后恢复示例数据。
- 原图使用 Unsplash 公共演示照片（鞋、腕表、水杯）；示例尺寸用于呈现业务状态，不是照片文件元数据。图标复用客户端本地 Phosphor 字体和许可证。
- 本次没有修改 `frontend/`、`backend/` 或安装中的客户端。
- 未发布到外部托管；需要先选定方案，再实施正式页面。
