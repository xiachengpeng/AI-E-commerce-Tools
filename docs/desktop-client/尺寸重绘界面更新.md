## 使用

打开客户端 → 图片工具 → 尺寸重绘。左侧选择比例，右侧拖入、粘贴或选择本地图片，右上角开始。按全部/待处理/成功/失败/已跳过筛选；预览、单图更多菜单、失败重试、上传图床、下载 ZIP 和历史入口继续可用。更换本批图片会替换列表，处理中不可更换。

10 种比例、原图保留、批次比例锁定、历史恢复、单图删除、图片翻译与详情页流转都保留。界面字号继续跟随设置中的 14/16/18/20 档位，不修改生成图片或商家排版字号。
