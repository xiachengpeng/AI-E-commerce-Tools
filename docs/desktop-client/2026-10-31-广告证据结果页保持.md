# 广告证据保存结果页保持（2026-10-31）

## 问题与根因

保存广告证据后，成功结果页仅替换当前 DOM，未成为可恢复的页面状态。后台每 5 秒轮询研究资料，快照变化触发重绘时，页面按 coarse 阶段恢复为普通粗筛总览，导致成功提示和下一步入口消失。通用页面装饰逻辑也会覆盖重新渲染的结果标题。

## 修复范围

- 在商品页状态中记录当前保存结果，并绑定项目、商品与身份版本；同一身份的资料刷新保留结果页。
- 结果按最新服务端门槛渲染，服务端状态变化时不保留过期通过结论。
- 明确编辑、继续下一步或返回寻找广告时退出结果状态；不同身份不得复用。
- 结果页跳过普通阶段标题覆盖；已通过的粗筛总览增加“继续核对需求与竞争”按钮。
- 不改变后端证据、身份和版本门槛。

## 验证与边界

- 先复现轮询重绘丢失结果页的失败测试，修复后新增 7 项回归覆盖。
- 完整前端串行测试 985 项通过，0 失败；两个修改模块的语法检查、修改范围差异检查通过。
- 本机正式客户端已原位更新；应用签名、包校验及实际 HTTP 返回资源哈希验证通过。
- 数据库完整性检查通过，研究密钥与配置未变，现有商品、广告及粗筛通过状态保留。
- 原生 UI 实测：已保存的粗筛总览显示“继续核对需求与竞争”，点击后进入同一商品第三步；客户端停留在该页。
- 保存后结果页跨轮询保持由回归测试验证；原生验收没有重新提交真实证据，没有发起收费 AI、采集或上传任务。
- 仅更新本机正式客户端，未重新制作客户 DMG。

本机测试及回退资料位于已忽略的 debug/coarse-result-20261031-001458/，完整测试日志为 debug/coarse-result-full-tests-final.log。
