## 已实现

设置 → 外部接口增加“详情页项目迁移”，与原 Listing、广告文案、排版模板迁移分开校验。支持导出当前未生成资料、已有成果，以及读取旧版详情项目或旧草稿；不开放任意运行任务导入。

- 包格式 `kind=detail-page-transfer, version=1`，内部仍沿用详情历史 `detail-page-project, version=2`。
- 最多 64 MiB JSON、单图 8 MiB、PNG/JPEG/WebP。检查签名并用浏览器真实图片解码，额外限制像素面积。
- 原图、模块图、原始模块图、模块文案开关、已有文案、SEO、样式、排版、语言、排序、事实及其确认来源按白名单保留。
- 导出把有效 blob 和本地静态图片装入文件。只读取当前来源 blob、当前站点或固定回环 API 的静态路径；不自动请求外部图片，不跟随跳转。
- 图片失效、文件超限、脚本/事件/凭据/未知包字段阻止整个操作，原资料保留。旧草稿没有保存的原图明确警告，不声称已迁移。
- 新建项目及模块实例标识，单独保留模块业务类型，映射原有长图顺序。运行和云端上传身份不复活。
- 选择文件只预览；确认只调用原有详情历史保存入口另存副本，不切换当前编辑器、不生成、不上传。保存失败保留包和现有编辑内容。
- 从历史打开迁移项目时不重新推荐模块，保留未确认事实；未知来源的旧名称保持未确认，名称与来源矛盾时拒绝导出。
