## 使用

设置 → 外观与字号 → 界面字号，选择偏小14px、标准16px、偏大18px、较大20px。立即调整当前设备的菜单、表单和界面文字，自动保存在当前客户端/浏览器；“恢复默认字号”回到16px。标题、正文与辅助说明保留层级，16px是界面基准字号，不是要求全部文字都相同大小。

同一级侧栏入口统一字号和字重，嵌套入口稍小。修复了按钮与分组标题原先16/14px不一致，以及旧展开侧栏important样式覆盖按钮的情况。

## 实现边界

- 仅本机 localStorage 键 `ai_ecommerce_interface_font_size`，取值仅14/16/18/20；非法值回默认，存储受限仍可本次调整并明确提示。
- 不修改后端、凭据、业务数据或任务授权。
- 应用样式的绝对px/rem字体按比例变化，em/%继承不重复放大，根字号不改。媒体查询、原有选择器与important优先级保持。
- 商品成果预览容器、DTC排版区域独立于界面字号；生成的位图、商家排版和导出保持原业务配置。
- 无新增依赖。仅前端资源更新，后端沿用已验收的连接测试版本。

核心文件：`frontend/js/interface_typography.js`、`frontend/js/settings.js`、`frontend/index.html`、`frontend/css/settings.css`、`frontend/css/research-design.css`。
