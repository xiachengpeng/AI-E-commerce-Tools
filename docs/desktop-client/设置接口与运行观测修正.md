## 测试边界

|服务|检查方式|不代表|
|---|---|---|
|Apify|读取当前账户|特定 Actor 的权限、采集结果或额度保证|
|SerpApi|读取账户信息|某个搜索来源一定可用|
|Firecrawl 研究用途|读取官方账户额度|目标网站一定可抓取|
|阿里云|GetTranslateReport 读取翻译报表|已执行翻译或拥有翻译写调用权限；报表权限不足也可能失败|
|飞书|认证后读取目标多维表格表清单|具有写权限；不会创建表或记录|

所有测试不提交采集、搜索、翻译、AI生成或飞书写入，不启动后台任务，不自动重试；拒绝重定向，固定官方地址。敏感请求地址不写入 HTTP 请求日志，原始响应和异常不返回浏览器。

技术依据：`backend/routes/integration_settings.py`、`backend/services/integration_connection.py`、`frontend/js/settings_research.mjs`、`frontend/js/research-workbench/settings.mjs`、`frontend/js/settings.js`。

接口：POST `/api/settings/integrations/{provider}/research/test`。沿用本机访问、研究会话、CSRF/Origin校验及 no-store 响应，不新增数据库表或修改业务数据。
