**Goal:** 将 SOP 全部已实现能力、源码、研究数据和证据归入 AI E-commerce Tools，最终解除远端及 iframe 依赖。

**Architecture:** 主 FastAPI 与原生 JavaScript 保留；研究通过内部 Facade 与显式生命周期接入。主历史和研究同用一份 SQLite，采集/同步由同一启动器管理的唯一本地 worker 执行，AI统一主路由。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy同步/异步、SQLite WAL、Pydantic、原生JS ES modules、Tailwind 3；迁入原研究SDK及Playwright。

**Spec:** [09-完整归并架构方案.md](09-完整归并架构方案.md)，2026-10-09 用户回复“确认”已批准该架构。**本计划尚待审核及执行方式选择，不将架构确认当作本计划已经执行。**

## Global Constraints

- 本机主项目为唯一源码与部署项目；主Python 3.12、9502/9503、原公开端点和业务行为保留。
- 最终一个API、一个SQLite文件、原生研究UI、唯一项目环境；worker可为同项目子进程。
- 不全面更换主技术栈；不因冲突删除原业务功能、研究数据或证据版本。
- 主库保留 `backend/history.db` 位置；私有研究数据根 `~/.local/share/ai-ecommerce-tools/research/`；测试仅用临时副本。
- 研究所有LLM请求走主AIRouter/retry_service；SDK内部重试关闭，未知结果阻断自动重放和供应商切换。
- 原Unknown、事实确认、identity/version围栏、引文校验、command_id、lease、attempt和预算保持。
- 切换期冻结源端写入与worker，只有一个执行者；本机文件锁不能代替跨机器交接屏障。
- 原件hash/VersionId/签名材料保持；证据不能受营销static TTL清理或公开托管。
- 不执行真实付费调用、采集、同步、上传或发布作为自动测试；外部链用fake transport。
- 既有主provider与binding不被迁移覆盖；凭据仅私有传输/存储，报告、fixture、日志和Git不含真实值。
- 完成必须实际验证远端退出后可运行；未验证外部能力和7天观察期分别登记，不冒称通过。

## Review Focus

1. 冻结后源端仍有云任务或未知同步回执：保留runID并查询状态，不能自动重新提交。（任务19/20）
2. 已开本地写入后要求退回远端：保留新增事件和证据，未核对增量之前拒绝恢复旧源worker。（任务20）
3. 研究旧浏览器草稿已发命令但没收到响应：恢复原command_id并查回执，不能变新ID制造重复项目。（任务17）
4. 大输入、错模型或引用hash变化：严格失败且保持旧成功结果，不能截断后确认或注入fallback。（任务10/15）
5. API与worker因工作目录不同误开第二份DB/锁：由同一RuntimePaths解析并测试真实子进程路径。（任务3/5）
