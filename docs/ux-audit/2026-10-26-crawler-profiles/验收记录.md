## 交付行为

- 设置和竞品“爬虫设置”弹窗共用唯一表单、同一套竞品账号；选品研究用途仍独立保留。

## 操作方式

1. 竞品分析 → 爬虫设置，或设置 → 外部接口 → Firecrawl → 竞品分析。
2. 点击新增账号，填写密钥与地址，保存；系统自动编号。
3. 从已保存账号选择要用的配置，可先测试连接。
4. 点击使用此账号；带“使用中”标记的账号供下一次分析使用。
