# 详情页模块默认未选择设计

## 目标

详情页生成器首次打开或刷新时，12 个模块均不默认选中，由用户自行选择需要生成的模块。

## 实现

- 将 `MODULES_CONFIG` 中所有模块的 `active` 默认值设为 `false`。
- 保留每个模块已有的张数和“包含文案”默认值。
- 保留现有模块点击切换逻辑。
- 保留“未选择模块时禁止生成并提示请至少选择一个模块”的校验。

## 范围

- 只改变新页面初始化时的默认选择。
- 不删除模块，不增加额外按钮。
- 已生成的历史项目继续按保存内容展示，不受默认配置改变影响。

## 验证

- `MODULES_CONFIG` 中不存在默认激活模块。
- 页面刷新后模块卡片全部为未选择状态。
- 用户点击模块后可以正常选中，并显示张数和“包含文案”控件。
- 完整前端测试通过。
