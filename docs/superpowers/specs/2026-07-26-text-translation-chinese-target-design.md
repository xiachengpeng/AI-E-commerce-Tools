# 文本翻译中文目标语言设计

## 目标

在“文本翻译”功能的目标语言多选列表中新增简体中文：

- 显示名称：`中文 (ZH)`
- 提交值：`Chinese`
- 可单独选择，也可与其他目标语言同时选择

## 实现

在现有静态语言多选列表中，将中文选项放在 English 后面。继续复用 `executeBatchTextTranslation()` 的通用逻辑，由它收集 `.lang-checkbox:checked` 的值并向 `/api/translate-text` 提交 `target_langs`。

后端已经按字符串列表处理目标语言，因此不新增接口、不修改模型，也不改动图片翻译、详情页或 Listing 的语言配置。

## 验证

- 页面中存在且只存在一个 `value="Chinese"` 的文本翻译复选框。
- 中文选项标签显示为 `中文 (ZH)`。
- 完整前端测试和 JavaScript 语法检查通过。
- 刷新当前本地页面后，下拉列表可见中文选项。
