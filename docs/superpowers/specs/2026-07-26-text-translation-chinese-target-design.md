# 文本翻译目标语言设计

## 目标

在“文本翻译”功能的目标语言多选列表中支持简体中文和泰语：

- 显示名称：`中文 (ZH)`
- 提交值：`Chinese`
- 可单独选择，也可与其他目标语言同时选择

泰语选项：

- 显示名称：`ไทย (TH)`
- 提交值：`Thai`
- 可单独选择，也可与其他目标语言同时选择

## 实现

在现有静态语言多选列表中保留中文选项，并新增泰语选项。继续复用 `executeBatchTextTranslation()` 的通用逻辑，由它收集 `.lang-checkbox:checked` 的值并向 `/api/translate-text` 提交 `target_langs`。

后端已经按字符串列表处理目标语言，因此不新增接口、不修改模型。详情页和图片翻译另有各自的语言配置，当前同样支持泰语，但不复用文本翻译的静态复选框。

## 验证

- 页面中存在且只存在一个 `value="Chinese"` 的文本翻译复选框。
- 中文选项标签显示为 `中文 (ZH)`。
- 页面中存在且只存在一个 `value="Thai"` 的文本翻译复选框。
- 泰语选项标签显示为 `ไทย (TH)`。
- 完整前端测试和 JavaScript 语法检查通过。
- 刷新当前本地页面后，下拉列表可见中文和泰语选项。
