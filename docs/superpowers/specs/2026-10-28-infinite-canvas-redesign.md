# 图片工具：参考 Infinite Canvas 的节点画布

状态：用户已确认；2026-10-28。参考项目固定源码版本 `9cd3deacbcc598361807afc16c059a80dd18b6f9`，MIT 许可。

## 目标

用户希望界面和操作尽量与 canvas.best 的无限画布一致；已安装的上一版仅是多图编辑工作区，没有节点和连线，与预期不符。以图片工作流为第一期：在同一无限画布上布置图片、文字及生成节点，连线或选择上游内容，进行文生图、图生图和局部编辑；一张画布能保留多张素材和生成结果。与参考保持一致的画布布局、交互、视口、节点选择与工具位置，而不只换颜色。

提供的画布链接在隔离浏览器中跳转到画布库，无法读取用户本人画布内容；本方案依据参考站新建画布的实际界面、图片节点交互以及开源源码，不声称复刻了其私人画布的具体节点。

## 实施选择

已考虑两条途径：自行实现相似的节点画布，或复用参考项目的前端画布和节点实现。用户已表示尽可能一致并优先移植，故选择后者；保留 MIT 版权和许可及项目要求的作者标识，锁定版本，先以隔离验证确定组件、打包及依赖边界。参考前端是 React/Vite，并以浏览器本地持久化；它的现成生成链可直接携带密钥请求服务商，不能原样接入。本项目是静态前端 + FastAPI：通过本地后端接口适配图片操作、项目与素材持久化，复用现有图片能力绑定和服务端密钥，不在浏览器存储密钥或直连模型服务商。移植时关闭原有直接请求、可执行模型插件及远程代理旁路，并验证浏览器网络请求和密钥边界。

## 体验与边界

- 保持主应用统一侧栏；进入「图片工具 → AI 图片画布」显示参考项目风格的节点编辑器，包含左侧节点列表、中央可平移缩放画布、底部工具与缩放控件、节点旁上下文操作及生成面板。用户可添加、拖动、缩放、连接、选择和删除文字或图片节点，保存并重新打开画布；节点及连线保持来源关系。
- 图片节点可填写提示词，接受文字和一张或多张上游图片作为参考，结果以新节点保留；支持单图局部编辑与遮罩，遮罩外原始像素由本地合成保护。图片数量、尺寸和比例仅在当前模型及后端可验证支持时开放；不支持或不确定时明确提示，不声称通用兼容。
- 图像配置沿用主设置中绑定的图片服务，提交前展示实际服务、模型、参考与费用提示；配置发生变更则重新确认。每次生成可恢复状态，未知结果保留核对入口，绝不在超时或错误后自动重复收费请求。多张输出如果需要多个请求，必须逐项记录操作身份和结果并在提交前告知请求数量。
- 用户明确本次只要图片：不提供视频、音频、Agent 及相关入口，不引入新的密钥设置。仅保留图片工作流需要的文本节点和画布控件。
- 不覆盖或删除已安装上一版的画布数据。两种格式分开标记和保存，保留上一版画布入口用于查看与导出；只有验证无损后才提供明确的导入，不能以空文档覆盖旧项目。
- 项目、节点、连接、视口、提示词、遮罩和素材持久化到用户数据目录，版本管理、保存冲突、中断恢复和资源配额须明确；不得只依赖浏览器临时存储。适配上游画布及素材的分离存储，用户须能看到保存失败并保留未保存工作。生成任务冻结画布、节点、节点版本、输入及连线顺序；切换或删除后迟到结果仍归属原项目并可恢复。
