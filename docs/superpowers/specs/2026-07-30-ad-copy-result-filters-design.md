# 广告文案结果组合筛选设计

## 目标

为“广告文案结果”增加“广告平台 + 创意角度”组合筛选，解决 9 种创意角度和多个平台内容同时展开导致页面过长、难以定位的问题。

筛选仅作用于前端已有结果，不重新调用 AI、不改变后端响应、不修改历史数据。

## 筛选维度

### 广告平台

平台筛选项包括：

- 全部平台
- Facebook
- Google
- Pinterest PIN

平台项根据本次结果动态生成：

- 仅展示至少在一个创意角度中实际存在的广告平台。
- “全部平台”始终存在。
- 不为未生成的平台显示不可用按钮。
- 平台顺序固定为 Facebook、Google、Pinterest PIN。

### 创意角度

创意角度筛选项包括：

- 全部创意角度
- 本次结果中的每一个创意角度

具体角度名称和标识来自本次返回的 `styles` 数组，不另外维护一套硬编码名称。

## 默认状态

每次载入一份新广告结果时：

- 平台默认选择结果中第一个实际存在的平台。
- 平台优先顺序为 Facebook、Google、Pinterest PIN。
- 创意角度默认选择“全部创意角度”。
- 如果结果中没有任何平台数据，平台回退为“全部平台”。

“新广告结果”包括：

- 新生成成功的结果。
- 从历史记录恢复的结果。
- 其他调用 `renderAdsData()` 载入的完整结果。

旧结果的筛选条件不会延续到新结果。

## 筛选栏布局

- 筛选栏位于“广告文案结果”标题区域下方、产品摘要和创意卡片上方。
- 筛选栏在结果区域内保持固定，用户滚动长结果时仍可切换。
- 平台使用分段按钮。
- 当前平台按钮显示明确的品牌色选中状态：
  - 全部平台：橙色。
  - Facebook：蓝色。
  - Google：绿色。
  - Pinterest PIN：红色。
- 创意角度使用单选下拉框，避免 9 个按钮占据两排空间。
- 筛选栏沿用现有白色、浅灰边框、圆角和紧凑字号，不改变页面整体设计语言。

## 前端状态

新增两个模块级状态：

```javascript
let currentAdsPlatformFilter = 'all';
let currentAdsStyleFilter = 'all';
```

平台值固定为：

- `all`
- `facebook`
- `google`
- `pinterest`

创意角度值使用结果中每个 style 的规范标识：

- 优先使用 `style.id`。
- 兼容使用 `style.styleId`。
- 缺失标识的项使用稳定的结果数组索引回退值，仅供本次结果筛选。

## 数据流

### 载入新结果

`renderAdsData(data)` 负责：

1. 保存 `currentAdsData`。
2. 从所有 styles 中解析实际可用平台。
3. 重置平台筛选为第一个可用平台。
4. 重置创意角度为 `all`。
5. 构建筛选控件。
6. 渲染产品摘要和经过筛选的创意卡片。

### 修改筛选

平台按钮或创意角度下拉框变化时：

1. 更新对应筛选状态。
2. 使用现有 `currentAdsData` 重新渲染结果主体。
3. 不发起网络请求。
4. 保持结果滚动容器当前滚动位置。

为避免切换筛选时错误重置状态，完整结果载入与基于现有数据的筛选重绘使用两个明确入口：

- `renderAdsData(data)`：载入新结果并重置筛选。
- `renderFilteredAdsResults()`：使用当前状态重绘，不重置筛选。

## 产品摘要

- Product 产品摘要始终显示。
- 产品摘要不受平台或创意角度筛选影响。
- 产品摘要只创建一次于当前筛选后的结果视图中。

## 卡片显示规则

### 创意角度筛选

- 选择“全部创意角度”时显示全部 style 卡片。
- 选择具体角度时，只显示标识匹配的 style 卡片。

### 平台筛选

- 选择 Facebook 时，每张匹配卡片只渲染 Facebook 区块。
- 选择 Google 时，每张匹配卡片只渲染 Google 区块。
- 选择 Pinterest PIN 时，每张匹配卡片只渲染 Pinterest 区块。
- 选择“全部平台”时，每张匹配卡片渲染其所有平台区块。
- 如果某个 style 不包含当前平台，该 style 不显示为空卡片。

平台与创意角度条件同时生效。

## 复制行为

每张创意角度卡片的“复制”按钮跟随当前平台筛选：

- Facebook 筛选只复制 Facebook 文案。
- Google 筛选只复制 Google 文案。
- Pinterest PIN 筛选只复制 Pinterest 文案。
- “全部平台”复制该 style 包含的所有平台文案。
- 创意角度名称和创意逻辑始终保留。
- Pinterest 描述和标签继续使用当前无空格合并格式。

复制函数接受显式平台参数，避免在异步点击或重绘过程中读取到错误的全局状态：

```javascript
copyAdsStyleText(style, platformFilter)
```

按钮创建时将当前卡片对应的平台筛选值传入。

## 空结果状态

如果组合筛选后没有任何创意卡片：

- 产品摘要继续显示。
- 结果主体显示“当前筛选条件下没有结果”。
- 显示“重置筛选”按钮。
- 点击后恢复：
  - 平台为第一个实际可用平台。
  - 创意角度为全部。
- 重置不调用 AI。

正常情况下，创意角度选项来自现有结果、平台选项来自实际数据，因此空结果主要用于兼容部分缺失平台数据或异常历史结果。

## 错误处理和兼容

- 缺失 `styles` 或 `styles` 非数组时按空数组处理。
- style 缺失 `id` 时兼容 `styleId`，再回退到稳定索引标识。
- style 缺失某个平台对象时不渲染对应区块。
- 筛选控件的文本使用安全文本节点，不插入模型返回的 HTML。
- 动态创意角度名称使用现有安全文本渲染方式。
- Facebook、Google、Pinterest 的字段布局保持不变。
- 现有 AI 请求、产品名称辅助识别、Emoji 规则和后端接口保持不变。

## 可访问性

- 平台筛选使用 `button` 元素。
- 当前平台按钮使用 `aria-pressed="true"`。
- 平台按钮具备可见焦点状态。
- 创意角度下拉框关联可见标签或 `aria-label`。
- “重置筛选”使用可聚焦按钮。

## 测试

### 控件和默认值

- 结果区域包含平台分段按钮容器和创意角度下拉框。
- 仅实际存在的平台生成按钮。
- 默认选择第一个可用平台。
- 默认创意角度为全部。
- 平台按钮正确更新 `aria-pressed` 和选中样式。

### 组合筛选

- Facebook + 全部角度仅渲染 Facebook 区块。
- Google + 指定角度仅渲染匹配角度的 Google 区块。
- Pinterest + 指定角度不显示其他平台。
- 全部平台恢复匹配卡片的所有平台区块。
- 当前平台缺失的 style 不生成空卡片。

### 状态

- 切换筛选不调用 `fetch`。
- 切换筛选保留滚动位置。
- 新结果载入重置旧筛选。
- 历史恢复通过 `renderAdsData()` 使用相同重置逻辑。

### 复制

- 单平台筛选的复制内容只包含该平台。
- 全部平台复制所有存在的平台。
- 复制保留创意角度名称和逻辑。
- Pinterest 合并描述格式保持不变。

### 空结果与安全

- 无匹配卡片时显示空结果提示和重置按钮。
- 重置恢复第一个可用平台与全部角度。
- 动态角度名称和平台内容保持纯文本插入。

### 回归

- 商品摘要始终显示。
- 新生成请求、产品名称、Emoji、图片上传和历史恢复不受影响。
- Facebook、Google、Pinterest 原有字段展示不变。

## 非目标

- 不增加后端筛选参数。
- 不重新生成或重新请求广告文案。
- 不增加多选平台筛选；平台为单选或全部。
- 不增加创意角度搜索、排序、收藏或分页。
- 不把筛选状态持久化到数据库或浏览器存储。
- 不修改 AI 输出结构或 9 种创意角度定义。
