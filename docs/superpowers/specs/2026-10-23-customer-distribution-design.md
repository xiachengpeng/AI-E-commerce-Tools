## 产品边界

- 第一版面向 Apple Silicon Mac；版本 0.2.0，客户应用名 `AI E-commerce Tools Customer`，固定身份 `local.ai-ecommerce-tools.customer`。
- 数据根目录固定为 `~/Library/Application Support/AI E-commerce Tools Customer/workspace`；浏览器独立 profile 位于其父目录。升级不能更换这些身份。
- 首次安装产生全新数据库、证据命名空间和两把独立随机签名密钥；不能复制现有迁移授权，不能使用临时离线绕过。
- 初始化在私有同级临时目录完成后原子发布；已有未知目录、损坏所有权、较新版本数据均拒绝覆盖。
- 专门的 `fresh_install` 签名授权保持既有 HMAC、数据集/代次、首次候选哈希、消费后账本和证据门槛。与历史迁移路径分别验证，不虚构源冻结证明。
- 不注入默认 API 凭据、不预置个人业务数据。品牌示例保留主动加载按钮，取消自动预置。
- 首次引导说明用途、密钥入口及研究运行规则；后台默认暂停。运行规则必须明确确认，启用采集需要明确费用提示。飞书仅可启用观察轮询，不扩大既有有限执行授权。
- 手动升级同一应用身份，启动变更版本前在所有桌面子进程锁空闲时完成私有完整备份，失败则拒绝启动；本版不自动升级研究 schema、不实现自动更新服务。
- 不生成公开下载链接。未取得 Developer ID 签名及 Apple 公证、未经另一台 Mac 验证时，制品明确标注“客户测试候选包”，不得称为正式发行版。

## 验收

新目录启动研究可读写且零历史、零密钥配置、后台暂停；重启不重置数据和密钥；升级保留客户创建记录和配置并生成可恢复备份；未知/篡改/降级拒绝；常规前后端和桌面回归通过。包内隐私审计通过，代码签名校验通过，原客户端与数据不变。实际收费调用与跨设备验证不在本机模拟为通过。
