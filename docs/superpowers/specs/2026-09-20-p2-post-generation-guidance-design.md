# Phase P2: 全量文案与流程深度重塑 — 生成后后链路闭环与业务交付设计规范

## 1. 业务背景与问题分析 (Background & Problem)

在跨境电商实际业务运营中，非专业卖家使用 AI 工具的核心诉求是**“一站式搞定商品上架与推广闭环”**。
当前系统在完成了 P0（跨模块流转死锁解除、Google RSA 字符刚性限制、关键词语义纠偏）和 P1（商详首屏引导预设、消极空状态重塑、黑话通俗化、Listing 局部润色对比暂存）之后，仍存在以下业务流程断点与文案体验断层：

1. **商详生成完成后的“虚无感”与交付断点**:
   - 当前在 `details.js` 中，全案生成（`generateDetailPlan`）执行完毕后，仅弹出一个冷冰冰的 toast（如 `生成完成：成功 6，降级 0，失败 0`）。
   - 界面停留在长长的画廊或 DTC 图文列表中，缺少醒目的交付指引。卖家不知道下一步该做什么（导出长图？复制 HTML 描述到 Shopify？还是上传到 WordPress 图床？还是接着去写 Listing？）。
2. **竞品分析报告读完后的“流转断崖”**:
   - 竞品分析报告包含市场定位图、对战卡、VOC 痛点、综合评估等超长内容（通常需滚动多屏）。虽然在报告最顶部有流转按钮，但当卖家逐屏阅读到报告最底部时，没有呼应的“落地行动指南 (Next Actionable Steps)”，必须费力滑回顶层。
3. **全局操作反馈与报错的“冷硬与无解”**:
   - 多处提示语仍存在工程师思维的冷硬提示（例如直接弹出 `生成失败`、`图片读取失败`、`当前批次已创建，如需改尺寸请重新上传一批图片` 等），未明确告知卖家“失败原因是什么”以及“具体该如何解决/重试”。

## 2. 解决方案与核心设计 (Architecture & Design)

### 2.1 商详生成后交付中心 (Post-Generation Delivery Hub)
在详情页结果区域（`#resultArea`）的底部（紧随画廊与独立站容器之后），设计并实现自适应交付指引卡片 `#detailDeliveryHandoffCard`：
- **触发机制**:
  - 当全案生成完成（至少有 1 个成功模块）或还原历史项目时自动渲染并展示。
  - 当清空或重置视图时自动隐藏。
- **视觉与信息架构**:
  - **头部状态总结**: 展示庆祝勋章、完成模块数统计及清晰提示（`🎉 全案视觉企划制作完成！请选择下一步交付或发布操作：`）。
  - **3 大核心交付动作**:
    1. `长图拼接导出`: 触发画板排版长图设计器 (`openLongImageBuilder()`)。
    2. `复制独立站 HTML`: 触发独立站轻量自包含 HTML 描述弹窗 (`openDetailDtcHtmlModal()`)。
    3. `云图床托管/替换链接`: 触发多目标云存储托管抽屉 (`openPdpAssetHostingModal()`)。
  - **2 大跨模块业务流转**:
    1. `立即生成配套 Listing`: 提取当前详情页的产品名称与卖点，无缝流转至 Listing 模块并切换标签 (`transferDetailToListing()`)。
    2. `立即创作配套广告`: 提取当前详情页的产品名称与核心卖点，流转至 Ads 模块并切换标签 (`transferDetailToAds()`)。
  - **物料包一键打包**:
    - `一键导出全套物料包 (ZIP)`: 触发 `exportFullLaunchKit()`。

### 2.2 竞品分析报告底部行动呼吁 (Competitor Analysis Bottom CTA Handoff)
在竞品分析单品模板（`#xp-single-template`）与多品矩阵模板（`#xp-matrix-template`）的最末端，分别新增 `#xp-singleBottomHandoff` 与 `#xp-matrixBottomHandoff` 行动卡片：
- **触发机制**:
  - 在 `xp_renderSingleTemplate` 与 `xp_renderMatrixTemplate` 渲染完成时呈现。
- **信息与操作结构**:
  - 引导文案: `💡 竞品情报与战术已深度解析完成，建议立即将核心洞察转化为商业战力：`
  - 四大快速转化行动:
    - `[ ✍️ 注入并编撰 Listing ]`: 胜出卖点与关键词直达 Listing 模块。
    - `[ 📣 注入并创作投放广告 ]`: 痛点反差钩子直达广告模块。
    - `[ 🎨 注入并策划视觉详情页 ]`: 产品参数与差异化卖点直达商详模块。
    - `[ 🗂️ 存入营销画像档案库 ]`: 保存为全局品牌与商品画像。

### 2.3 友好化与诊断性 Toast 体系重塑 (Constructive Feedback & Actionable Diagnostic Toasts)
系统性审查并重构全站非专业卖家高频接触的 Toast 提示：
1. **Details 模块**:
   - `生成失败` -> `卖点提炼失败：请检查网络连接，或前往【AI设置】确认已配置并启用文本大模型。`
   - `重绘失败` -> `模块重绘失败：生图服务未正常响应，请检查生图渠道状态或稍后重试。`
   - `图片读取失败` -> `图片读取失败：文件可能损坏或格式不兼容，请重新上传 JPG/PNG/WebP 格式图片。`
   - `尚未生成任何模块` -> `尚未生成任何视觉模块：请先在左侧勾选所需模块并点击【一键生成详情页】。`
   - `没有可导出的详情页项目` -> `没有可导出的详情页：请先生成视觉模块后再打包物料。`
2. **Listing 模块**:
   - `暂无文本可复制` -> `当前暂无已生成的 Listing 内容，请先生成后再复制。`
   - `请填写必填项：产品名称与核心卖点` -> `请补充商品信息：产品名称与核心卖点均为必填项，有助于 AI 精准创作。`
   - `标题不能为空` -> `标题内容不能为空，请输入至少一个有效词语。`
3. **Ads 模块**:
   - `复制失败` -> `复制失败：请检查浏览器剪贴板权限，或手动长按/选中文本复制。`
   - `请上传商品图片或输入商品名称` -> `请至少提供商品名称或上传 1 张商品白底图，以便 AI 解析卖点并撰写广告。`
4. **Square Redraw 模块**:
   - `当前批次已创建，如需改尺寸请重新上传一批图片` -> `当前批次已锁定尺寸：如需更换目标宽高比，请先清空当前图片列表后重新添加。`
