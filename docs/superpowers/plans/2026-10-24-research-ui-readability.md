**目标：** 依据本轮截图及24个实际渲染页面/状态的审查，修正拥挤、微小文字、误导进度、空白状态和窄窗口问题，保留现有业务功能。

**依据：** 用户要求仔细检查并修改；保持既有蓝白设计和共享侧栏。截图来自本轮实际客户端及隔离的原生模块。隔离页禁止业务写入、远程素材、收费服务，测试计划状态仅为版式夹具，不作为业务门槛通过依据。

## 最小实现

- [x] 核对面板分为状态、操作/禁用原因、筛选/费用说明；沿用原按钮、ID、任务确认和预算规则。
- [x] 搜索词工具栏正常布局，避免悬在标题右侧；增加无结果及筛选为空的可操作说明。只切换已有来源，不自动审核或搜索。
- [x] 记住核对面板展开状态，切换筛选后不折叠。
- [x] 独立 `research-polish.css` 集中维护可读性修正；不重构旧设计样式，不影响其他模块或主设置凭据编辑器。
- [x] 表单控件/标签、说明、渠道卡片、队列和表格统一可读字号与按钮尺寸；窄窗口自然重排；避免固定高度形成多层滚动。
- [x] 工具/规则配置不显示业务进度；阶段选择页文案使用清楚的页面名称。
- [x] 回归先 RED→GREEN；24页面前后截图、1024宽度/20px字号、实际客户端展开核对面板验收；完整前端及桌面测试、包校验。
- [x] 独立代码复核，更新本机客户端和验收文档；客户旧安装包不自动覆盖。
