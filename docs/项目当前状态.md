## 当前运行架构

研究源码已纳入本项目 `backend/modules/research/rabbit_hole/`，原生前端在 `frontend/js/research-workbench/`；兼容源码/夹具保存在 `backend/modules/research/compat/`。运行使用主 FastAPI、主前端及 SQLite；现行启动链不需要备用机、SSH隧道、19503端口或研究iframe。

| 内容 | 当前实现依据 |
| --- | --- |
| 启动 | 根目录 `.venv/bin/python run.py`；API 9503，前端 9502 |
| 页面入口 | `http://127.0.0.1:9502/index.html`，不使用 `file://` |
| 前端服务 | `frontend_server.py`；研究及集成设置的限定路径转发到固定本机后端，不重试写请求 |
| 主数据库 | 默认 `backend/history.db`；测试/部署可由 `SQLITE_DB_PATH` 指定 |
| 研究路由 | `backend/routes/research.py`、`research_workbench.py`；由 `backend/main.py` 注册 |
| 外部接口配置 | 主设置页，`frontend/js/settings_research.mjs`、`backend/routes/integration_settings.py`；不维护两套独立编辑入口 |
| 研究后台任务 | `run.py:local_worker_command` 仅在显式启用、`worker_mode=active` 且激活签名及账本有效时启动唯一worker；页面能打开不等于worker已运行 |
| 研究私有材料 | 默认 `~/.local/share/ai-ecommerce-tools/research/`，不属于公开营销静态目录 |

停止时在所属启动终端按 Ctrl+C；重启前核对本项目进程与9502/9503端口。不要按历史PID终止进程，不要同时启动旧研究API或第二个worker，不要通过恢复旧数据库解决新界面问题。`run.py`可能在CSS缺失时调用已有构建命令，因此新环境须先准备前端依赖。

## 选品研究业务流程

先创建研究项目和目标市场，再准备/审核关键词并明确发起搜索。主界面展示五阶段，服务端仍保留十项权威步骤：

1. **找线索**：准备、解释、审核搜索词，再搜索公开广告；初始词使用保存的研究方向与目标。采集方式及多API账号按设置显式选择。
2. **核实商品**：核对商品与广告，再核实广告年龄、活跃状态与独立素材。可以先保留深挖、暂存观察或淘汰并填写原因；观察/淘汰可恢复，不强迫每条线索完成所有表单。
3. **需求与竞争**：补充趋势和渠道证据，完成广告与商品页分析（漏斗）。两项任务直接显示，来源扩词仍从可靠原文入口执行。
4. **算清利润**：填写真实订单成本、物流及风险，再检查证据并计算评分。不能拿页面售价直接替代采购成本或把未知费用写成零。
5. **做决定**：保存测试/备选/观察/淘汰；测试候选再完成测试计划和真实结果，最后复盘。十步中的决定、测试、复盘在此阶段分别可达。

`services/journey.mjs:journeyGroups`仍是底层四组业务投影，不应把它误写成顶部仅有四阶段。`components/workflow-controls.mjs`提供阶段内任务入口。点击阶段只是查看，不自动保存、付费搜索或放宽门槛。

“继续选品”优先恢复有效项目焦点，无焦点时回到最近有结果的来源词；焦点商品已有有效非测试决定则进入复盘。完成词的“重新搜索并补充”明确引用原完成任务，保存旧结果；同一补采意图去重，失败恢复须指向该轮任务，不重新播放旧任务。批次预览按已审核ready/blocked与项目上限选择，空批次不可提交。

未达标证据可以保存，但不会因此变为通过。广告年龄满足30天不等于连续投放30天：没有完整历史时显示“未验证”，不能以一次近期活跃观察证明期间从未停投。

自动核对不能替代所有人工确认；缺失证据、成本或测试结果保持未知，不填零、不制造“已通过”。评分与决定由原后端门槛校验。报告用于展示当前证据、缺口、决定和下一步，不保证盈利。任务持久日志与设置页进程内实时日志是两种记录。

素材缓存为有界内存缓存（默认32条/64MiB），复用同来源在途请求及已加载媒体；离开工作台会清理，来源变化/失效、首次读取和淘汰后重新读取仍可能加载。来源广告须精确绑定，不用其他广告或设计示例补图。

付费采集、AI调用和飞书写入须按业务确认执行；同步预览与批准分开，版本/摘要不匹配或结果不确定时不得盲目重发。只读查看、截图和本地模拟不能证明真实外部写入成功。
