Business reads and writes require `X-Research-Token`. Evidence object paths reject traversal/encoded traversal/absolute paths/backslashes.
- Narrow controller-authorized `backend/routes/research.py` changes delegate the existing guard/session checks to this same boundary. Existing v1 DTOs/client dispatch remain unchanged.
- Narrow `backend/main.py` changes include the router and enter/exit its lifecycle beside existing main lifecycle. Only explicit enabled `mode=local` opens Task 3 prepared runtime with `allow_commands=True, allow_external=False`; DB path is main DB_PATH, private root is `~/.local/share/ai-ecommerce-tools/research`. No migration, initial key creation, app mount, old HTML/assets/listener, old secret, worker, or external default is activated. Initialization failure produces research-only503 and safe `('initialization_failed',)` diagnostics; main cleanup/adapter shutdown remain owned by main.
- Successful responses, HTTP errors and framework validation errors use `Cache-Control: no-store`; SSE retains four slots, Last-Event-ID validation and slot release. Source feasibility preserves original explicit authorization/subscription warnings and does not advertise dormant collectors as healthy.
- Screenshot delivery reuses original local `read_screenshot` VersionId/hash verification via runtime's EvidenceStore; action lookup is project-bound and result object path must match market/action.
- Signed `/evidence-file?token=...` originally lives in runtime/server.py, not workbench.py. It is included in parity. Original LocalObjectClient validates signature/expiry/VersionId; native handler additionally validates object path, saved action result, existing owning project/market, committed manifest VersionId and hash. Optional `project_id` further binds caller context while legacy token-only query remains supported for saved action evidence. Unbound/deleted/mismatched evidence fails404. Signing material stays private. Existing signing method still returns the legacy path; native UI Tasks13/15 must use the new endpoint while retaining the token.
- Original `stop_action` may abort a submitted Apify run. Default dormant handler preflights **raw project-bound DB rows** (public get_action DTO hides payload), including active owned dependencies, and refuses submitted external jobs503 before mutation/transport unless an explicit stop service is supplied.
